更新级别：建议

> **一句话**：Star 入口从一个变成两个——GitHub、Gitee 各一个按钮，首页底部也拆成两个入口，两个平台都点得到。

## 1. Star 入口：两个平台各一个

- 「关于与开源信息」的 Star 卡原来只有「去 GitHub 点 Star」一个按钮，Gitee 用户点不到自己常用的那个。现在并排放两枚：**「去 GitHub 点 Star」和「去 Gitee 点 Star」**，点哪个都直接进对应仓库首页。
- 卡片正文分两段讲清楚：第一段是「任选一个就行」——GitHub 是主仓，Gitee 是国内镜像，访问快一些，代码完全一样；第二段是挽留话术——**两个都用得上就两边各点一颗**，GitHub 和 Gitee 的 Star 各算各的，谁也替不了谁；国内的人多半只在 Gitee 上搜，海外的人只翻 GitHub，两边都留一颗，这工具才更容易被下一个需要它的人找到。
- 打不开浏览器时不再只弹一句「失败了」：把仓库链接复制到剪贴板，并提示「链接已复制」，自己粘到浏览器里就行。

## 2. 首页底部

- 底部原来是一个「★ 点个 Star」，现在拆成 **「★ GitHub」和「★ Gitee」** 两个可点入口，跟版本号、开源仓库并排一行，想点哪个点哪个。

## 3. README 与仓库页

- README 的界面章节换成真机带壳截图（首页、设置一级、关于页上下两屏，中英各两份），放到表格里并排，手机上看也不会挤。原来那张旧的单图引用删掉了。
- README 中英两处的 Star 说明同步改成双平台版本，把「两个都点最管用」的理由写进去。

## 4. 版本

- 1.0.3.0 → 1.0.3.1（只动末段）；versionCode `1000301`。
- 覆盖安装即可，设置、悬浮球位置、语言选择全部保留。

## English · Release Notes

Level: recommended

> **In one line**: one star link became two — a GitHub button and a Gitee button, plus both links in the home footer, so either platform is one tap away.

### 1. Star links: one per platform

- The star card under "About & open source" used to offer only "Star on GitHub", which left Gitee users without their usual repository. It now shows **"Star on GitHub" and "Star on Gitee"** side by side, each opening the corresponding repository.
- The card text explains both cases: first "either one is enough" — GitHub is the main repository, Gitee is the China mirror, faster to load, identical code; then the ask — **if you use both, one star on each is the most help**, because GitHub and Gitee count their stars separately and neither stands in for the other; people in China mostly search Gitee and people elsewhere only look at GitHub, so a star on both is what lets the next person find this.
- When no browser can be opened, the link is copied to the clipboard and a toast says so, instead of only reporting a failure.

### 2. Home footer

- The single "★ Star it" link is now **"★ GitHub" and "★ Gitee"**, sitting on the same line as the version and the repository link.

### 3. README and repository page

- The README screenshot section now uses real framed device captures (home, settings level 1, about page in two halves, Chinese and English), laid out in a table so they stay readable on a phone. The old single-image reference is gone.
- Both the Chinese and English star paragraphs were rewritten for the two-platform setup, including the reason to star both.

### 4. Version

- 1.0.3.0 → 1.0.3.1 (last segment only); versionCode `1000301`.
- Installs over the previous build; settings, ball position and language choice are preserved.
