# 发布指南

一次发版的完整流程。按顺序做，别跳步。

## 0. 本机构建环境（实测可用）

| 组件 | 路径 |
| --- | --- |
| JDK 17 | `C:\Users\YB\.workbuddy\toolchains\android\jdk-17` |
| Android SDK 34 | `C:\Users\YB\.workbuddy\toolchains\android\sdk` |
| Gradle 8.7 | `C:\Users\YB\.workbuddy\toolchains\android\gradle` |
| 签名证书 | `D:\android-build\AutoSwipe\autoswipe-release.jks`（不入库） |

```powershell
$env:JAVA_HOME="C:\Users\YB\.workbuddy\toolchains\android\jdk-17"
$env:ANDROID_HOME="C:\Users\YB\.workbuddy\toolchains\android\sdk"
gradle assembleRelease
```

双击 `打包.bat` 等价于上面两条。

## 1. 改版本号（只有一处）

`app/build.gradle.kts`：

```kotlin
val appVersionName = "1.0.0.2"
```

`versionCode` 自动算：主×1000000 + 次×10000 + 修订×100 + 补丁。**不要手填**。

同时更新：
- `CHANGELOG.md` 顶部加一节；
- `使用说明.txt` 第一行的版本号。

## 2. 构建并核对产物

```powershell
gradle assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`。发版前至少核对这些：

```powershell
# 版本号与包名
aapt2 dump badging app-release.apk | Select-String "package:"
# 签名
apksigner verify --print-certs app-release.apk
```

预期：`versionName='1.0.0.x'`、`versionCode=<算出来的值>`、`Signer #1 certificate DN: CN=AutoSwipe ...`。

## 3. 命名与存放

```
AutoSwipe-<版本号>.apk          例：AutoSwipe-1.0.0.2.apk
```

放到仓库外的 `release/<版本号>/`（**不要提交进 git**），Release 上传时用这个名字。
不要改名成中文、不要加 `-arm64`（本工程没有原生库，一份包所有机型通用）。

## 4. 先推代码，再发 Release

顺序不能反：tag 要指向推代码那一刻的提交，否则「AGPL 要求提供可构建源码」就不成立。

```powershell
git add -A
git commit -m "release: 1.0.0.x"
git tag v1.0.0.x
git push origin main            # Gitee
git push origin v1.0.0.x
git push github main            # GitHub
git push github v1.0.0.x
```

## 5. Release 正文（两平台同一份）

第一行顶格写更新级别，程序靠这行决定提醒力度：

```markdown
更新级别：建议

> **一句话**：不超过 100 字，只说最关键的那几条。

## 1. 修复：xxx（安卓）

具体说明一两句。

## 2. 新增：xxx（安卓）

具体说明。
```

- `更新级别：强烈建议` → 弹窗标题变红、关闭前挽留一次，但仍可关；
- 不写或写 `更新级别：建议` → 普通提醒；
- 「一句话」会被读成弹窗顶部的摘要，`##` 小标题会被读成条目，所以别在正文里堆无关内容；
- **不要勾 pre-release**，否则 `/releases/latest` 会跳到旧版；
- 两平台正文必须一致，否则两边用户看到的弹窗不一样。

## 6. 上传安装包

GitHub：`gh release upload` 或网页上传，资产名必须是 `AutoSwipe-<版本号>.apk`。
Gitee：Release 附件上传同一份文件（同名）。

程序检查更新的逻辑：优先从**文件名**里解析版本号；文件名没有版本号时退回 tag。
所以**资产名带版本号**是最稳的。

## 7. 发完自检

1. 装旧版 → 打开 → 应弹出「发现新版本 v1.0.0.x」；
2. 点「立即更新」→ 应用内下载 → 核对包名版本 → 拉起系统安装器；
3. 覆盖安装后打开 → 版本号已变；
4. 断网再打开 → 静默跳过，不弹窗、不卡住。
