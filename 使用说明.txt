自动翻页 · 使用说明  v1.0.1.0（安卓）
================================================

完整说明、版本更新记录、常见问题都在开源仓库：
https://github.com/neurotracee/auto-swipe
（国内镜像：https://gitee.com/bio234/auto-swipe）
本文件只讲最常用的部分。


【一、安装】
1. 从 Releases 下载 AutoSwipe-1.0.0.1.apk。
2. 系统提示「未知来源」时允许安装；装新版本直接覆盖，不用先卸载。


【二、开两个开关】
1. 无障碍：设置 → 无障碍 → 已安装的服务 → 「自动翻页」→ 开启。
   · Android 13 及以上，侧载应用的开关默认是灰的：
     先到「应用信息 → 右上角菜单 → 允许受限设置」，再回来开启。
2. 悬浮窗：设置 → 应用 → 特殊权限 → 悬浮窗 → 「自动翻页」→ 允许。
   · 只想先看看球长什么样，可以只开悬浮窗：小球不需要无障碍也能出来。


【三、开始与暂停】
1. 回到应用，点「显示小球」——屏幕边上出现一个深灰圆形。
2. 暂停态图标是白色右三角 ▶：点一下开始。
3. 点完会等 1.5 秒（留时间切回视频 App），然后才开始上滑。
4. 运行中图标变成两道竖杠 ⏸：再点一下立刻停。
5. 小球可以按住拖到任意位置，松手后位置会记住。
6. 不想看到球：应用内点「隐藏小球」（会把正在跑的循环一起停掉）。


【四、它的节奏】
· 每次间隔在 2–30 秒之间随机取值，不是固定节奏。
· 起手位置每次都变：横向在屏幕中间 40%–60% 之间随机落点，纵向在 73%–80% 之间，
  终点在 27%–35% 之间，起止横向最多差 5% 屏宽——有变化，但不会漂到屏幕边上。
· 轨迹不是直线：带一点轻微 S 形弯曲和细波动，每次方向、幅度都不同。
· 速度也不是匀速：起步慢、中间快、收尾缓，一整次滑动约 0.38–0.64 秒，
  手指全程不抬起，看起来就像真人在滑。
· 首页会显示「已翻 N 页 · 下次约 X 秒 · 上次间隔 Y 秒」，都能对上。


【五、什么时候会自己停】
· 息屏：自动暂停。
· 系统里关掉无障碍开关：循环和小球一起收干净。
· 隐藏小球：循环一起停，不会出现「界面显示停了、背地里还在滑」。


【六、检查更新】
右上角齿轮 → 设置页。
· 「更新检查方式」：自动检查（启动时）/ 手动检查。自动每次启动在后台静默查一次，没网就跳过；
  手动则只有点「检查更新」才联网。
· 「更新源」：Gitee（建议中国大陆用户）/ GitHub（海外用户），单选；选的连不上会自动换另一个，
  并写明换了。
· 「版本与更新」：显示当前版本，右侧「检查更新」当场查一次。
· 发现新版本点「立即更新」：应用内下载、核对包名与版本，再交给系统安装器。
  不走浏览器，避免 Gitee 把文件存成「…apk.zip」。


【六·二、设置里其他开关】
· 「界面语言」：中文 / English，切换立即生效，不用重启。
· 「外观」：跟随系统 / 浅色 / 深色，随手机的深色模式自动切换那档选「跟随系统」。
· 「悬浮球」：显示 / 隐藏小球；隐藏时正在跑的循环一起停。
· 「运行状态 → 息屏时自动暂停」：默认开；关掉后黑屏也继续滑。
· 「关于与开源信息」：版本、署名、开源协议、两个仓库地址、权限与第三方组件清单。


【七、已知限制】
· 部分应用对无障碍手势有限制（安全键盘、支付页、部分游戏与部分极速版），
  这些界面滑不动，是目标应用的限制，不是本应用故障。
· 本应用不读取屏幕、不模拟点击；它只会在当前界面上滑一下，翻成什么由目标应用决定。
· 这是辅助工具，不要拿它刷量、刷互动——那属于目标应用规则禁止的行为。

AutoSwipe · User guide  v1.0.1.1 (Android)
================================================

Full guide, changelog and FAQ live in the repository:
https://github.com/neurotracee/auto-swipe
(mirror: https://gitee.com/bio234/auto-swipe)

[1. Install]
Download AutoSwipe-<version>.apk from Releases, allow "unknown sources", and install.
New versions install over the old one; no uninstall needed.

[2. Enable two switches]
· Accessibility: Settings → Accessibility → Installed services → "AutoSwipe" → on.
  Android 13+: sideloaded apps are blocked by default — go to App info → menu →
  "Allow restricted settings" first, then come back.
· Overlay: Settings → Apps → Special access → Display over other apps → AutoSwipe → allow.
  The ball needs only this permission, so it can be shown before accessibility is on.

[3. Start and pause]
Tap "Show ball" — a dark circle appears. Tap ▶ to start; the icon becomes ❚❚, tap again to stop.
The first swipe comes 1.5 s after you tap. Drag the ball anywhere; its position is remembered.

[4. Timing]
Every gap is a random 2–30 seconds. Each swipe picks a slightly different start and end point,
curves a little, and eases in and out over about 0.38–0.64 s. It stops when you turn the screen
off (configurable), hide the ball, or switch accessibility off.

[5. Settings]
Gear icon → two-level settings: language (中文 / English), appearance (system / light / dark),
floating ball, pause on screen off, update check mode, update source (Gitee / GitHub),
version + check button, and "About & open source" (credits, AGPL-3.0-or-later, repo links,
permissions, third-party components).

[6. Known limits]
Some apps restrict accessibility gestures (secure keyboards, payment pages, some games and lite
builds). This app does not read the screen and does not tap buttons, so it cannot bypass that.
It is an assistive tool: do not use it to farm views, likes or engagement.
